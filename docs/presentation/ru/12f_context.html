Правка детали в контексте

Edit открывает деталь на своей вкладке, остальные детали вокруг полупрозрачны.

View › Assembly Context включает и выключает их.

Вернувшись в сборку, InCad спросит, обновлять ли деталь.

Остальные детали видны только для ориентира: их нельзя выбрать, и они не сохраняются.
