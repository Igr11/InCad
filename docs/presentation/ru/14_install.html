Установка

Четыре шага через Addon Manager

1

Распакуйте архив и скопируйте путь к папке InCad: Option+Cmd+C

2

Settings › Addon Manager › Custom repositories › «+», вставьте путь

3

Tools › Addon Manager › InCad › Install

4

Перезапустите FreeCAD и выберите верстак InCad

Чтобы FreeCAD сразу запускался в InCad: Settings › Workbenches › Available Workbenches › Startup › Default workbench: InCad

Подробности и ручная установка: README_ru.txt в архиве. Полное руководство: InCad-manual_ru.pdf

Путь нужен к внутренней папке InCad, а не к zip и не к верхней папке. При первом запуске выберите Part.
