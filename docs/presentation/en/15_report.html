How to help

Found a bug? Send four things

Steps: what you did and what you expected

Log: the file ~/Library/Logs/InCad.log

Model: the .FCStd file, if you can share it

Versions: build name, macOS and FreeCAD; after a crash, macOS's report too

Журнал важнее всего: по нему видно, что InCad делал перед ошибкой. Снимок экрана тоже очень помогает, если что-то выглядит не так.
