Install

Four steps with the Addon Manager

1

Unzip the archive and copy the path of the ProstoCAD folder: Option+Cmd+C

2

Settings › Addon Manager › Custom repositories › “+”, paste the path

3

Tools › Addon Manager › ProstoCAD › Install

4

Restart FreeCAD and choose the ProstoCAD workbench

To start FreeCAD in ProstoCAD: Settings › Workbenches › Available Workbenches › Startup › Default workbench: ProstoCAD

Details and the manual install: README.txt in the archive. The full manual: ProstoCAD-FreeCAD-manual.pdf

Путь нужен к внутренней папке ProstoCAD, а не к zip и не к верхней папке. При первом запуске выберите Part.
