Install

Four steps with the Addon Manager

1

Unzip the archive and copy the path of the InCad folder: Option+Cmd+C

2

Settings › Addon Manager › Custom repositories › “+”, paste the path

3

Tools › Addon Manager › InCad › Install

4

Restart FreeCAD and choose the InCad workbench

To start FreeCAD in InCad: Settings › Workbenches › Available Workbenches › Startup › Default workbench: InCad

Details and the manual install: README.txt in the archive. The full manual: InCad-manual.pdf

Путь нужен к внутренней папке InCad, а не к zip и не к верхней папке. При первом запуске выберите Part.
