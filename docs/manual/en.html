1About InCad

InCad gives FreeCAD the look and the working habits of Autodesk Inventor and Alibre Design.

InCad is a workbench for FreeCAD: a module that FreeCAD loads like its own Part Design or Sketcher workbenches. When InCad is active it replaces FreeCAD's toolbars and panels with an Inventor-style interface:

  • a ribbon with tabs that change with what you are doing (part, sketch, assembly);
  • a Model Browser with one history for the whole part, sketches under the features that use them and an End of Part marker you can drag;
  • a Parameters panel where every dimension and feature value has a name and can be used in formulas;
  • feature dialogs with a live preview, OK, Apply + and Cancel;
  • marking menus on the right mouse button, and Inventor's mouse navigation;
  • Inventor-like sketching, assemblies with constraints, joints and degrees of freedom.

FreeCAD underneath

Everything InCad makes is ordinary FreeCAD geometry: a part is a FreeCAD Part Design body, a sketch is a Sketcher sketch, an assembly uses FreeCAD's own Assembly joints. Your files stay normal .FCStd files that FreeCAD opens with or without InCad.

The FreeCAD button at the top right of the window (Return to FreeCAD) brings FreeCAD's own interface back at any time; choose InCad in FreeCAD's workbench selector to come back.

A file that was not made in InCad opens as well. The Model Browser then says Not an InCad part and offers Convert to InCad Part (for a file with one solid) and Open in FreeCAD.

This build: 0.4.0, a test build

0.4.0 is a test build. Assemblies came in 0.2.0, Move Face in 0.3.0. New in 0.4.0: InCad's own sketch Offset, the Concentric constraint, Move Face on round walls, Fillet / Chamfer on a whole face or a smooth chain, any axis (also two points) for a Circular Pattern, a clearer sketch look and many fixes from testing — CHANGES.txt has the full list.

Please: save your work often and work on copies of files that matter to you. If something looks wrong, tell us — chapter 11 says what to send.

2Installation

Install InCad once with FreeCAD's Addon Manager; updating is the same few steps.

Requirements

  • A Mac with Apple Silicon (M1, M2, M3, M4 …).
  • FreeCAD 1.1 for macOS Apple Silicon (InCad is tested with FreeCAD 1.1.3), from www.freecad.org/downloads.php.

Intel Macs, Windows and Linux are not supported in this build.

Install with FreeCAD's Addon Manager (recommended)

  1. Unzip the InCad archive. You get a folder with README, CHANGES and this manual, and a folder named InCad. Put the unzipped folder somewhere it can stay for now, for example in Downloads.
  2. Copy the path of the InCad folder — the one inside the unzipped folder: select it in Finder and press ⌥ ⌘ C (Copy as Pathname). The path ends in …/InCad, not in .zip and not in …-macOS-arm64.
  3. Start FreeCAD and open FreeCAD ▸ Settings… (Preferences…). Choose Addon Manager in the list on the left.
  4. Under Custom repositories click +. Paste the path from step 2 into Repository URL. Leave Branch as it is. Click OK, then OK again to close Settings.
  5. Open Tools ▸ Addon Manager. Find InCad in the list, select it and click Install.
  6. Restart FreeCAD and choose InCad in the workbench selector.

After the install the unzipped folder is no longer needed.

Install by hand (if the Addon Manager way does not work)

  1. Quit FreeCAD.
  2. In Finder choose Go ▸ Go to Folder… (⇧ ⌘ G) and paste ~/Library/Application Support/FreeCAD/v1-1/Mod. If there is no Mod folder, go to …/FreeCAD/v1-1 and create a folder named Mod there.
  3. Copy the InCad folder from the unzipped archive into that Mod folder. The result must be …/FreeCAD/v1-1/Mod/InCad/InitGui.py — not …/Mod/InCad/InCad/InitGui.py.
  4. Start FreeCAD and choose InCad in the workbench selector.

The first start

The first time, InCad asks what to make and in which units: Part (one part file) or Assembly (place and constrain part files), and Millimeters (mm, ISO threads listed first) or Inches (in, UNC/UNF threads listed first). With Remember my choice checked, New makes the same kind of file without asking next time. Click Create.

To bring the question back, turn on Tools ▸ Options ▸ Ask on New on the ribbon, or choose ⚙ ▸ Units for New Files ▸ Ask every time.

Start FreeCAD in InCad

To make InCad the workbench FreeCAD starts with: FreeCAD ▸ Settings… ▸ Workbenches ▸ Available Workbenches ▸ Startup ▸ Default workbench: InCad. (In FreeCAD 1.1 this setting is under Workbenches, not under General.)

Update to a new build

  1. Tools ▸ Addon Manager ▸ select InCad ▸ Uninstall. Quit FreeCAD.
  2. Unzip the new build and copy the path of its InCad folder (⌥ ⌘ C).
  3. FreeCAD ▸ Settings… ▸ Addon Manager ▸ Custom repositories: select the old path, remove it with −, and add the new path with +.
  4. Tools ▸ Addon Manager ▸ InCad ▸ Install, then restart FreeCAD.

Installed by hand: quit FreeCAD, replace the Mod/InCad folder, start FreeCAD.

Uninstall

Tools ▸ Addon Manager ▸ select InCad ▸ Uninstall, then restart FreeCAD. Installed by hand: quit FreeCAD and delete the Mod/InCad folder. You may also delete the log file ~/Library/Logs/InCad.log. Your .FCStd files keep working in plain FreeCAD.

3The InCad window

A short tour: what each area of the window is for.

3.1 Title strip

The strip at the very top holds quick buttons — New, Open, Save, Undo, Redo and Update — the name of the file, and on the right Light / Dark, FreeCAD (Return to FreeCAD) and ⚙ (InCad settings).

Update recomputes the model and redraws the browser and the view. Use it if the view and the browser ever seem out of step with the model; in an assembly it also brings in parts that changed (see 9.10).

3.2 Menus

InCad keeps a short menu bar: File (New, New Assembly, Open, Save, Save As, Close, Quit), Edit (Undo, Redo) and View (Light / Dark, Zoom All, Home View, Shaded, Wireframe, Assembly Context, Parameters, Return to FreeCAD, Ribbon Size). Everything else is on the ribbon and in the marking menus.

3.3 The ribbon

The ribbon's tabs depend on what is open:

ModeTabs
No file, or a file not made in InCadGet Started (New, New Assembly, Open), View
A part3D Model, Inspect, Tools, View
Editing a sketchSketch, View
An assemblyAssemble, View

A button with a small arrow is a split button: it runs the command shown, and its arrow lists the variants (for example Rectangle ▸ Center Rectangle, 3-Point Rectangle …). Hover over a button for its full name and a tip. View ▸ Ribbon Size (or ⚙ ▸ Ribbon Size) switches between Small and Large. Appendix B lists every command of every tab.

3.4 The Model Browser

The MODEL panel on the left is the history of the part, as in Inventor:

  • The top row is the part. Under it: Origin (XY, XZ and YZ Plane, X, Y and Z Axis, Center Point), then Solid Bodies (n) when the part has more than one solid (chapter 7), then the features in the order they were made — one history for every solid of the part.
  • A sketch sits under the feature that uses it. A sketch row shows ✓ when it is fully constrained, or how many degrees of freedom are left (2 DOF).
  • End of Part marks where the model ends. Drag it up to see (and work on) the part as it was at that point; features below it are greyed and not computed. Right-click a feature ▸ Move End of Part Here does the same. Drag it back down to the end when you are done.
  • Row colours: a feature that failed is red (hover over it for the reason); a suppressed feature is greyed and struck through; a hidden item is dimmed.

Click a row to select it: the faces the feature made light up in the view (figure 2). A hidden plane, axis, point or sketch is shown while its row is selected and hidden again when you select something else. Double-click a row to edit it: a feature opens its dialog, a sketch opens for editing, a plane starts a new sketch on it. With ⇧ or ⌘ you can select several rows.

Right-click a row for its marking menu (chapter 4):

RowCommands
A feature or sketchEdit, Move End of Part Here, Suppress / Unsuppress, Rename, Show in Window, Start 2D Sketch, Delete, Hide / Show
A solid (Solid Bodies)Hide / Show, Rename, Show in Window, Delete
An origin plane or axisStart 2D Sketch, Hide / Show
  • Show in Window lights up the feature's faces and zooms the view to them. Its opposite, Show in Browser (right-click a face in the view), opens the browser at the feature that made that face.
  • Suppress / Unsuppress turns a feature off without deleting it. A thread is suppressed together with the helper steps InCad made for it; picking a feature's profile sketch means the feature.
  • Delete removes a feature together with everything InCad made for it (thread profiles, Boolean helpers, assembly cuts), as one undo step. ⌫ or Del deletes the selection. When the delete affects more than the row — a solid used by a Boolean, the main solid, a Split with pieces — InCad asks first and says what will go.
  • Hide / Show works on solids, assembly parts, origin planes and axes, the Center Point and sketches.

3.5 The Parameters panel

Below the browser, PARAMETERS lists the part's values in three columns: Name, Value (what you typed — a number or a formula) and Result.

  • Model parameters (shown in the accent colour) are made automatically: every sketch dimension and every feature value gets the next free name d0, d1, d2 …; assembly constraint values are named after the constraint (Mate1, Angle1 …). Type a new name over a model parameter to rename it — formulas that use it follow.
  • Your own parameters: click +, type a name, press Tab and type the value (Width, 40 mm). Use the name in any value box or dialog field.
  • Change a value in the Value column and the model updates.
  • − removes the selected parameter. A value that is still used (by a feature or a formula) is not removed: the status line says what uses it. This is how you clean up values left behind by deleted features.
  • While a value box or a dialog field is open, click a parameter's name to insert it into the formula.

View ▸ Windows ▸ Parameters (or the marking menu) moves the keyboard focus to the panel.

3.6 Values, units and formulas

Wherever InCad asks for a length or an angle you can type:

  • a number, in the file's units (12), or with units (12 mm, 0.5 in, 30°);
  • a parameter name (d3, Width);
  • a formula (d0/2, Width - 2*d3, d3*2).

A value that is a formula updates whenever the values it uses change.

3.7 The status line

At the bottom of the window: on the left, what to do next (for example "Pick a plane or a flat face for the new sketch") and messages — in orange or red when something did not work, so look here first when "nothing happens". On the right: the units of the file (mm · deg), while sketching the sketch's freedom (DOF: 3 or Fully constrained ✓ — click it to see the free geometry), and the size of the part (2 solids · 14 features).

3.8 Light, dark and the settings menu

Light / Dark on the title strip (also View ▸ Appearance and the marking menu) switches the theme in one click. The ⚙ menu holds InCad's settings:

⚙ menuChoices
ThemeMatch macOS, Light, Dark
Ribbon SizeSmall, Large
Units for New FilesAsk every time, Always millimeters, Always inches
Dimension DisplayHow sketch dimensions are labelled: Value (40), Name (d3), Expression (d3 = 40)
Mouse NavigationOn: InCad's mouse (LMB+RMB orbit, right-click menu). Off: FreeCAD's own navigation style applies.

3.9 Undo and Redo

⌘ Z undoes, ⇧ ⌘ Z redoes (also the title strip buttons and the NW / NE slots of the marking menu). Every operation is one undo step: a feature made in a dialog, a delete with its helpers, a hide, a drag of an assembly part. Inside a feature dialog, Undo steps back through the dialog's own changes. Undo also works in a sketch.

While a feature dialog is open, commands that would interfere with it (Save, Undo outside the dialog, editing a sketch) are refused with "Finish the … dialog first". Click OK or Cancel first.

3.10 Files

New (⌘ N) makes a part or an assembly (as chosen at the first start), File ▸ New Assembly always an assembly. Open (⌘ O), Save (⌘ S), Save As (⇧ ⌘ S) work on the file in front. Close (⌘ W) asks whether to save changes (Save, Don't Save, Cancel); Quit (⌘ Q) asks about every changed file. Each open file has its own tab above the view.

5Sketching

Sketches work as in Inventor: draw roughly, then dimension and constrain. Every dimension has a name you can use in formulas.

5.1 Starting a sketch

  1. Select a flat face of the part or a plane (in the view or the browser) — or select nothing.
  2. Press S, or click 3D Model ▸ Sketch ▸ Start 2D Sketch, or right-click ▸ Start 2D Sketch (N in the marking menu).
  3. With nothing selected, InCad shows the origin planes and a small panel New sketch on with XY · Top, XZ · Front and YZ · Right: click a button, or click a plane or a flat face in the view. Esc or Cancel gives up.

Double-clicking a plane in the browser also starts a sketch on it. To edit an existing sketch, double-click it in the browser (or right-click ▸ Edit).

To leave the sketch: Sketch ▸ Exit ▸ Finish Sketch, N in the marking menu, or Esc (the first Esc stops a running tool).

5.2 Drawing tools

All on Sketch ▸ Create. The tools are FreeCAD's Sketcher tools; split buttons hold the variants.

Sketch ▸ Modify: Fillet and Chamfer (sketch corners), Trim (X), Extend, Offset. Sketch ▸ Pattern has the sketch patterns (5.9) and Mirror.

Offset (InCad's own): click a line — the whole shape it belongs to is taken (a rectangle, a polygon, a chain drawn line by line); ⌘-click adds more shapes. The copy follows the pointer; a click places it. Corners stay sharp, a single line gives one parallel line, a circle or an ellipse gives a ring. One dimension drives the offset and the value box opens on it. Geometry selected before the command is taken at once. Mirror and the patterns also take the whole shape from a click on one side.

Typing values while drawing. While a tool draws, type the length, radius or angle directly; Tab moves to the next field. Esc or Stop Tool (marking menu) ends the tool.

Delete geometry or dimensions: select them and press ⌫ or Del.

5.3 Dimensions

  1. Press D (or Sketch ▸ Dimension, S in the marking menu).
  2. Click a line, a circle, two points or two lines, and place the dimension.
  3. A value box opens: d3 = 40 mm. Type the value (or a formula) and press Enter or ✓; Esc or ✕ cancels. A value that cannot be used turns the box red and says why.

Double-click a dimension to change it later. Every dimension gets a name (d0, d1 …) and appears in the Parameters panel, where you can rename it (Width) — see 3.5.

Formulas. In the value box, click another dimension in the sketch or a parameter in the Parameters panel to insert its name: d0/2, Width - 2*d3. A formula may use other dimensions and parameters, but not a reference (driven) dimension of the same sketch.

⚙ ▸ Dimension Display chooses how dimensions are labelled: the value (40), the name (d3) or both (d3 = 40).

5.4 Constraints

Sketch ▸ Constrain: Coincident, Concentric (two circles, arcs or ellipses: their centres are tied), Horizontal, Vertical, Parallel, Perpendicular, Tangent, Equal, Symmetric, Fix and List (the Constraint List, 5.5). Select the geometry, then click the constraint (or click the constraint, then the geometry).

The status line shows the sketch's degrees of freedom — DOF: 3, or Fully constrained ✓. Click it, or Sketch ▸ Format ▸ Show Free Geometry, to select the geometry that can still move.

Sketch ▸ Format ▸ Show / Hide Constraints hides or shows the constraint symbols (dimensions stay); F8 shows them, F9 hides them.

5.5 The Constraint List

Open it with Sketch ▸ Constrain ▸ List, or right-click in the sketch ▸ Constraint List. It lists every constraint of the sketch with what it ties and its value — including the ones that have no symbol to click, such as coincident points and a point on a line.

  • Pick a line or a point in the sketch: the list shows only that element's constraints. Pick nothing to see them all.
  • Select a row to see its constraint in the sketch.
  • Check rows (or Select all) and press Delete selected. This is one undo step.
  • Constraints that hold a sketch pattern together, and dimensions used in a formula, are kept; the window says why.

5.6 Deleting constraints with the right button

Right-click a line or a point in the sketch: the marking menu's list then has a Delete … entry for each of its constraints (for example Delete Horizontal, or Delete Distance (Line 2) d4 = 20 mm), Delete all constraints (n), and Constraints…, which opens the Constraint List for that element.

5.7 Project Geometry and construction

Sketch ▸ Insert ▸ Project Geometry brings edges and points of the part into the sketch. As in Inventor, projected edges are normal lines, ready to be part of a profile. They follow the part when it changes.

Sketch ▸ Format ▸ Construction works two ways:

  • with geometry selected (also projected edges), it switches that geometry between normal and construction;
  • with nothing selected it is a mode: everything you draw is construction until you click it again.

Construction geometry does not take part in profiles; use it for axes and helper lines. It is drawn orange and dashed, thinner than the normal lines — a projected edge switched to construction too.

5.8 Seeing the sketch

  • Slice Graphics (F7, Sketch ▸ Format) cuts away the part in front of the sketch plane, so you can see a sketch inside the part.
  • Look At (marking menu) turns the view straight onto the sketch.
  • In the dark theme the part is drawn darker while a sketch is open, so the sketch's lines stand out (the part's own colour does not change).
  • After Finish Sketch, a sketch that no feature uses and that is an open contour (a path for a Sweep, say) stays visible in the model; a closed sketch, and any sketch a feature uses, is hidden. Hide / Show overrides this for any sketch.

5.9 Sketch patterns

Sketch ▸ Pattern repeats sketch geometry. The copies are real sketch geometry, tied to the original: change the original and the copies follow.

Edit Pattern: double-click a copy, or select a copy and right-click ▸ Edit Pattern. Delete Pattern (right-click on a copy) removes the copies; the original stays. If you delete single copies, the pattern is rebuilt the next time you edit it.

6Part features

Every feature opens a dialog with a live preview. This chapter first explains how the dialogs work, then each feature with what to pick and what each option means.

6.1 How feature dialogs work

  • Select first or pick later. Select the faces, edges or sketch first and then click the command — or click the command and pick in the view or the browser while the dialog is open. The highlighted field takes the picks. Click another pick field (Select…) to make it take the next picks. While you pick, the shape as it was before the feature is shown, so you can reach every face.
  • The profile. Extrude and Revolve take the only finished sketch no feature uses yet automatically; if there are several, select one. If a sketch has crossing lines, InCad shows its areas: click the one to use.
  • Preview. Every change shows on the model at once.
  • Values. Type numbers with or without units, names or formulas (3.6). The ▲ ▼ arrows next to a value — and the ↑ ↓ keys — change it by one unit (1 mm, 1°, 1/16 in); with ⇧ by ten. A formula cannot be stepped. The parameter's name is shown after the field's label, for example Distance (d19); click a parameter in the Parameters panel to insert its name.
  • Choices. Options are buttons; long lists wrap four to a row. A choice that cannot be used with the current picks is greyed out. Choosing an option that needs a pick starts that pick.
  • Buttons. OK makes the feature and closes the dialog. Apply + makes it and keeps the dialog open for one more of the same kind. Cancel or Esc leaves everything as it was.
  • Errors appear in red at the bottom of the dialog, in plain words ("Pick the cylindrical face to thread"). Sometimes the dialog offers a button with a way around the problem.
  • Editing. Double-click a feature in the browser (or right-click ▸ Edit) to open its dialog again with its values.

6.2 Extrude E

3D Model ▸ Create ▸ Extrude. Pulls a closed sketch profile into a solid, or cuts with it.

FieldChoices and meaning
OperationJoin (add material), Cut (remove), Intersect (keep only what the extrusion and the part share), New Solid (a separate solid, chapter 7). Cut is chosen for you when the sketch lies on or inside the material, Join otherwise.
ExtentsDistance; To Next (up to the next face of the part — if nothing is in the chosen direction, it goes toward the part); Through All; To (up to a Face you pick, flat or curved, or a work plane).
DistanceThe length (10 mm).
Direction→ the default side, ← the other side, ⇆ symmetric (half each way), ⇄ 2 two sides with their own lengths (Distance 2, 5 mm).
TaperDraft angle of the sides (0°).

A Join that does not touch the part becomes a solid of its own; the status line says so. Join and Cut can be switched later in the dialog, unless other features are built on this Extrude.

6.3 Revolve R

3D Model ▸ Create ▸ Revolve. Turns a sketch profile around an axis.

FieldChoices and meaning

6.8 Move Face

FieldChoices and meaning

The three ways the neighbours behave. Take a block with a chamfer on one top edge and pull the top face up:

NeighboursWhat happensWhen it refuses
InventorThe neighbours keep their angle and grow or shrink: the chamfer gets taller and the top face narrower. A hole through the face stays a hole, a boss wall slides along. A neighbour that is round across the move (a fillet, a cone): A neighbouring face is round: Inventor mode can't follow it yet — try Step or Together.
StepOnly the face moves, as a straight slab. A slanted or round neighbour stays as it was and a straight wall appears at its edge. Never because of a round or slanted neighbour; only “too large” (below).
TogetherThe face and the chamfers or fillets next to it move as one piece, keeping their size; the walls around them grow. Other messages: The move is too large: a neighbouring face would vanish (for example a face pushed in further than the chamfer next to it is wide; nothing changes), and A face to move is no longer there (an earlier feature removed the face; the Move Face row turns red); a face picked on another Solid is refused: The faces must be on this Solid. The To target is kept by its name, like other features' references.

7Several solids in one part

A part can hold several separate solids — for a tool and the part it cuts, or a part you will print in pieces.

How separate solids are made

  • Extrude with Operation ▸ New Solid.
  • An Extrude ▸ Join that does not touch the part (a box drawn away from it): it becomes its own solid automatically.
  • Split ▸ Keep all: every piece except the largest becomes a solid.
  • Boolean with Keep tool, or a "<Tool> fit" copy (Clearance on Tool).

The browser then shows Solid Bodies (n) with a row for each solid. The history stays one list: features of other solids name their solid.

Sketching on another solid

A new solid sketched on a face of another solid holds only its own piece; the solid below stays as it is. The sketch follows that face only when it projects edges of the other solid; otherwise the face only gave it its plane.

Hide, show, rename, delete

Right-click a solid's row: Hide / Show, Rename, Show in Window, Delete. A hidden solid is dimmed in the browser. Delete asks when the solid is used by a Boolean (both go together) or when it is the main solid (the next one becomes the main solid). Selecting a piece in the view and pressing ⌫ deletes that solid.

Make Assembly

When the pieces are ready, 3D Model ▸ Assemble ▸ Make Assembly turns every separate piece into a part file of its own and links them in a new assembly where they were. See 9.12.

9Assemblies

An assembly links part files and holds them together with constraints and joints, as in Inventor. The parts stay separate .FCStd files.

9.1 Starting an assembly

  • File ▸ New Assembly, or Get Started ▸ New Assembly with no file open.
  • New (⌘ N) makes an assembly too if you chose Assembly with Remember my choice. Tools ▸ Options ▸ Ask on New brings the question back.

An assembly links to part files, so it must be saved before the first part is placed. InCad does this for you: when you place the first part, a new assembly is saved next to that part under its own name; if a file of that name is already there, InCad asks for a name and a folder. Create asks you to save the assembly first.

9.2 Placing and creating parts

  1. Assemble ▸ Component ▸ Place (P) — or N in the marking menu.
  2. Choose a saved part (or assembly) file.
  3. The first part placed is grounded (fixed in place); the next ones are put beside it.

Create asks for a New part file name and makes a new, empty part file next to the assembly, placed in it. Ground grounds or ungrounds the selected part.

9.3 The assembly browser

In an assembly the browser shows the assembly, one row per part, and Relationships (n) with the constraints and joints.

  • Each part row shows its freedom: grounded, DOF 0 … DOF 6, or DOF ? when it could not be counted (hover for the reason). A suppressed part shows nothing.
  • Under each part row is the part's own history (its sketches and features). A click on one of those rows selects the part; a double-click opens the part file.
  • A hidden part is dimmed, a suppressed one struck through.
  • Right-click a part (row or in the view) for Edit, Hide / Show, Suppress, Remove from Assembly, Ground and the constraints (4.2).

9.4 Adding a constraint or a joint

  1. Click the constraint on Assemble ▸ Constrain or Assemble ▸ Joint — C is Mate, J is Rigid — or use the marking menu on a face or edge of a part.
  2. Pick the First item on one part and the Second item on another, in the 3D view. The preview moves the part at once.
  3. Set the Offset or Angle if the constraint has one, and Flip if the part faces the wrong way.
  4. OK (or Apply + for the next one).

The part that moves is the free one; a grounded part never moves. A constraint that cannot be met together with the others is refused: "Mate conflicts with the other constraints (it can't be met)". Offsets and angles are parameters named after the constraint — Mate1, Flush1, Angle1 … — and appear in the Parameters panel.

9.6 The Relationships rows

Every constraint and joint has a row under Relationships. Double-click a row to edit it. Right-click it for Edit, Delete, Suppress / Unsuppress and Rename. A suppressed constraint is struck through; the solver ignores it and its parts stay where they are. Bringing back a constraint that can no longer be met is refused.

9.7 Degrees of freedom

A part's degrees of freedom are the ways it can still move: up to three slides and three turns. InCad counts them against what holds the part (the other free parts are held still while it counts):

  • the part row says grounded, DOF n or DOF ? (9.3);
  • View ▸ Visual Style ▸ Degrees of Freedom (View tab of the assembly) draws Inventor's DOF symbols on every free part — a double arrow for each direction it can slide, an arc for each axis it can turn about (figure 12);
  • with that button off, the part under the pointer shows its symbol as a tip.

A fully constrained part (DOF 0) and a grounded part show no symbol.

9.8 Moving parts

Drag a free part with the left button: it moves only the ways its constraints still let it — a Mated block slides and turns on its face, an inserted pin turns in its hole. The other parts stay where they are, even free ones. A fully constrained part does not move (the status line says "… is fully constrained"); a drag on a grounded part says it is grounded.

The gizmo. Click a free part: its DOF symbol becomes a gizmo with an arrow for each direction it can slide and an arc for each axis it can turn about.

  • Grab an arrow to slide the part, an arc to turn it. Handles are easy to catch: the one under the pointer lights up.
  • The first arrow is up and down — straight up, or up the slope of a tilted face — where the part can move that way.
  • A click on empty space hides the gizmo.

Every drag that moved the part is one undo step ("Move part"); ⌘ Z puts the part back. While a constraint dialog is open, dragging is off.

9.9 Editing a part in the assembly

Right-click a part ▸ Edit (or double-click its row): the part opens in its own tab, with the other parts of the assembly drawn around it — grey, semi-transparent, at their real places. They are for reference only: they cannot be picked and are not saved in the part. Change the part as usual and save it.

View ▸ Assembly Context (View menu, or the View tab of the part) turns the other parts off and on.

9.10 Updating the assembly after a part changed

Back in the assembly's tab after a part changed, InCad asks: Parts of … changed. Update the assembly now?

  • Yes brings the changes in.
  • No leaves the assembly as it was; the top row of the browser then says ⚡ Needs update until you click Update on the title strip.

9.12 Make Assembly from a part

Model a product as one part with several solids (chapter 7), then turn it into an assembly in one step.

  1. Save the part — the new files go into its folder.
  2. 3D Model ▸ Assemble ▸ Make Assembly, or right-click in empty space ▸ Make Assembly.
  3. The dialog lists the new files: the Assembly name and one name per piece (Piece 1 (grounded), Piece 2 …) with its volume. Hover over a row to see the piece marked in the view. Change the names if you like.
  4. Click OK. The new assembly opens.
  • Every separate piece becomes a part file with its history; the assembly links them where they were, the largest piece grounded.
  • The original part is not changed.
  • Running Make Assembly again on the same part offers Replace existing files (with the names of the files already there), so the files of the earlier run are overwritten instead of asking for new names.   • A part that is one piece cannot be made into an assembly; split it first (Split ▸ Keep all) or make pieces as New Solid.

10Tips for 3D printing

InCad was made with printed parts in mind. A few habits save reprints.

  • Threads that fit. Thread and Hole ▸ Tapped have a Print clearance (on diameter), 0.2 mm by default (0.3 mm for a Print-friendly thread). Try it on a small test piece with your printer; raise it if a printed bolt is tight, lower it if it is loose. The Print-friendly thread standard has flat crests that print cleanly.
  • Lead-ins. Use Hole ▸ Chamfer (Start or Both ends) and Thread ▸ Chamfer so screws and nuts start easily.
  • Parts that fit into each other. Boolean ▸ Cut with Clearance (per side): on the Cavity to print the part with the hole, on the Tool to get a slightly smaller "fit" copy of the tool to print, Split for half on each.
  • Print the tool as well. Turn on Keep tool: the tool stays a visible solid of its own — the pin and the box with its hole.
  • Too big for the bed? Draw the cut lines in a sketch, Split ▸ Keep all, then Make Assembly: each piece becomes a part file you can export and print, and the assembly shows them together.
  • Weight and filament. Tools ▸ Material, then Inspect ▸ Mass Properties for the mass.
  • Fast work. Turn threads off (Threads) while modeling; turn them on before exporting.

11Troubleshooting and reporting a problem

When something does not work

  1. Read the status line and the red text in the dialog: InCad says why a command was refused and what to pick.
  2. A dialog is open? Commands like Save and Undo wait for OK or Cancel.
  3. A feature in red in the browser: hover over it for the reason, then edit it (double-click).
  4. The view or the browser looks out of step with the model: click Update on the title strip.
  5. Undo (⌘ Z) the last step.
  6. Still stuck: save under a new name, quit and restart FreeCAD.
  7. Return to FreeCAD always gives you FreeCAD's own interface on the same file.

Reporting a problem

Please send:

  • what you did, step by step, and what you expected instead;
  • the build name (the name of the zip file);
  • your macOS version and FreeCAD version (FreeCAD ▸ About FreeCAD);
  • the log file ~/Library/Logs/InCad.log (Finder ▸ Go ▸ Go to Folder… ▸ ~/Library/Logs);
  • if you can, the .FCStd file you were working on;
  • a screenshot if something looks wrong.

If FreeCAD crashed, macOS shows a crash report: please copy its text as well.

Known limits of this build

  • macOS on Apple Silicon only; FreeCAD 1.1 (tested with 1.1.3).
  • A test build. Save often and work on copies.
  • The interface is in English.
  • FreeCAD cannot shell a part that already has a modeled thread (InCad offers to shell before the thread).
  • Some offsets (clearances) fail on threads and other complex shapes; the dialog says so.
  • Move Face moves flat faces along their own direction and straight round walls outward / inward. In Inventor mode it cannot follow a neighbour that is round across the move yet (use Step or Together); Together inward next to fillets or chamfers on a round wall is refused for now.
