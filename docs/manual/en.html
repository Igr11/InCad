1About ProstoCAD

ProstoCAD gives FreeCAD the look and the working habits of Autodesk Inventor and Alibre Design.

ProstoCAD is a workbench for FreeCAD: a module that FreeCAD loads like its own Part Design or Sketcher workbenches. When ProstoCAD is active it replaces FreeCAD's toolbars and panels with an Inventor-style interface:

  • a ribbon with tabs that change with what you are doing (part, sketch, assembly);
  • a Model Browser with one history for the whole part, sketches under the features that use them and an End of Part marker you can drag;
  • a Parameters panel where every dimension and feature value has a name and can be used in formulas;
  • feature dialogs with a live preview, OK, Apply + and Cancel;
  • marking menus on the right mouse button, and Inventor's mouse navigation;
  • Inventor-like sketching, assemblies with constraints, joints and degrees of freedom.

FreeCAD underneath

Everything ProstoCAD makes is ordinary FreeCAD geometry: a part is a FreeCAD Part Design body, a sketch is a Sketcher sketch, an assembly uses FreeCAD's own Assembly joints. Your files stay normal .FCStd files that FreeCAD opens with or without ProstoCAD.

The FreeCAD button at the top right of the window (Return to FreeCAD) brings FreeCAD's own interface back at any time; choose ProstoCAD in FreeCAD's workbench selector to come back.

A file that was not made in ProstoCAD opens as well, with every tool: when it comes to the front it becomes a ProstoCAD part by itself (its largest Solid is the main one; a STEP opened as it is gets a Solid for each of its shapes, where they are). Save keeps that.

2Installation

Install ProstoCAD once with FreeCAD's Addon Manager; updating is the same few steps.

Requirements

  • A Mac with Apple Silicon (M1, M2, M3, M4 …).
  • FreeCAD 1.1 for macOS Apple Silicon (ProstoCAD is tested with FreeCAD 1.1.3), from www.freecad.org/downloads.php.

Intel Macs, Windows and Linux are not supported in this build.

Install with FreeCAD's Addon Manager (recommended)

  1. Unzip the ProstoCAD archive. You get a folder with README, CHANGES and this manual, and a folder named ProstoCAD. Put the unzipped folder somewhere it can stay for now, for example in Downloads.
  2. Copy the path of the ProstoCAD folder — the one inside the unzipped folder: select it in Finder and press ⌥ ⌘ C (Copy as Pathname). The path ends in …/InCad, not in .zip and not in …-macOS-arm64.
  3. Start FreeCAD and open FreeCAD ▸ Settings… (Preferences…). Choose Addon Manager in the list on the left.
  4. Under Custom repositories click +. Paste the path from step 2 into Repository URL. Leave Branch as it is. Click OK, then OK again to close Settings.
  5. Open Tools ▸ Addon Manager. Find ProstoCAD in the list, select it and click Install.
  6. Restart FreeCAD and choose ProstoCAD in the workbench selector.

After the install the unzipped folder is no longer needed.

Install by hand (if the Addon Manager way does not work)

  1. Quit FreeCAD.
  2. In Finder choose Go ▸ Go to Folder… (⇧ ⌘ G) and paste ~/Library/Application Support/FreeCAD/v1-1/Mod. If there is no Mod folder, go to …/FreeCAD/v1-1 and create a folder named Mod there.
  3. Copy the ProstoCAD folder from the unzipped archive into that Mod folder. The result must be …/FreeCAD/v1-1/Mod/InCad/InitGui.py — not …/Mod/InCad/InCad/InitGui.py.
  4. Start FreeCAD and choose ProstoCAD in the workbench selector.

The first start

The first time, ProstoCAD asks what to make and in which units: Part (one part file) or Assembly (place and constrain part files), and Millimeters (mm, ISO threads listed first) or Inches (in, UNC/UNF threads listed first). With Remember my choice checked, New makes the same kind of file without asking next time. Click Create.

To bring the question back, turn on Tools ▸ Options ▸ Ask on New on the ribbon, or choose ⚙ ▸ Units for New Files ▸ Ask every time.

Start FreeCAD in ProstoCAD

To make ProstoCAD the workbench FreeCAD starts with: FreeCAD ▸ Settings… ▸ Workbenches ▸ Available Workbenches ▸ Startup ▸ Default workbench: ProstoCAD. (In FreeCAD 1.1 this setting is under Workbenches, not under General.)

Update to a new build

  1. Tools ▸ Addon Manager ▸ select ProstoCAD ▸ Uninstall. Quit FreeCAD.
  2. Unzip the new build and copy the path of its ProstoCAD folder (⌥ ⌘ C).
  3. FreeCAD ▸ Settings… ▸ Addon Manager ▸ Custom repositories: select the old path, remove it with −, and add the new path with +.
  4. Tools ▸ Addon Manager ▸ ProstoCAD ▸ Install, then restart FreeCAD.

Installed by hand: quit FreeCAD, replace the Mod/InCad folder, start FreeCAD.

Uninstall

Tools ▸ Addon Manager ▸ select ProstoCAD ▸ Uninstall, then restart FreeCAD. Installed by hand: quit FreeCAD and delete the Mod/InCad folder. You may also delete the log file ~/Library/Logs/InCad.log. Your .FCStd files keep working in plain FreeCAD.

3The ProstoCAD window

A short tour: what each area of the window is for.

3.1 Title strip

The strip at the very top holds quick buttons — New, Open, Save, Undo, Redo and Update — the name of the file, and on the right Light / Dark, FreeCAD (Return to FreeCAD) and ⚙ (ProstoCAD settings).

Update recomputes the model and redraws the browser and the view. Use it if the view and the browser ever seem out of step with the model; in an assembly it also brings in parts that changed (see 9.10).

3.2 Menus

ProstoCAD keeps a short menu bar: File (New, New Assembly, Open, Save, Save As, Close, Quit), Edit (Undo, Redo) and View (Light / Dark, Zoom All, Home View, Shaded, Wireframe, Assembly Context, Parameters, Return to FreeCAD, Ribbon Size). Everything else is on the ribbon and in the marking menus.

3.3 The ribbon

The ribbon's tabs depend on what is open:

A button with a small arrow is a split button: it runs the command shown, and its arrow lists the variants (for example Rectangle ▸ Center Rectangle, 3-Point Rectangle …). Hover over a button for its full name and a tip. View ▸ Ribbon Size (or ⚙ ▸ Ribbon Size) switches between Compact (icons without names, which are in the tooltips: the lowest ribbon), Small and Large. Appendix B lists every command of every tab.

3.4 The Model Browser

The MODEL panel on the left is the history of the part, as in Inventor:

  • The top row is the part. Under it: Origin (XY, XZ and YZ Plane, X, Y and Z Axis, Center Point), then Solid Bodies (n) when the part has more than one solid (chapter 7), then the features in the order they were made — one history for every solid of the part.
  • A sketch sits under the feature that uses it. A sketch row shows ✓ when it is fully constrained, or how many degrees of freedom are left (2 DOF).
  • End of Part marks where the model ends. Drag it up to see (and work on) the part as it was at that point; features below it are greyed and not computed. It can also go above sketches, Texts and work planes: they are greyed and hidden while they are below it. Right-click a feature ▸ Move End of Part Here does the same. Drag it back down to the end when you are done.
  • Row colours: a feature that failed is red (hover over it for the reason); a suppressed feature is greyed and struck through; a hidden item is dimmed.

Click a row to select it: the faces the feature made light up in the view (figure 2). A hidden plane, axis, point or sketch is shown while its row is selected and hidden again when you select something else. Double-click a row to edit it: a feature opens its dialog, a sketch opens for editing, an origin plane starts a new sketch on it, a work plane opens its dialog. With ⇧ or ⌘ you can select several rows.

Right-click a row for its marking menu (chapter 4):

RowCommands
A feature or sketchEdit, Move End of Part Here, Suppress / Unsuppress, Rename, Show in Window, Start 2D Sketch, Delete, Hide / Show
A solid (Solid Bodies)Hide / Show, Rename, Show in Window, Delete
An origin plane or axisStart 2D Sketch, Hide / Show
  • Show in Window lights up the feature's faces and zooms the view to them. Its opposite, Show in Browser (right-click a face in the view), opens the browser at the feature that made that face.
  • Suppress / Unsuppress turns a feature off without deleting it. A thread is suppressed together with the helper steps ProstoCAD made for it; picking a feature's profile sketch means the feature.
  • Delete removes a feature together with everything ProstoCAD made for it (thread profiles, Boolean helpers, assembly cuts), as one undo step. ⌫ or Del deletes the selection. When the delete affects more than the row — a solid used by a Boolean, the main solid, a Split with pieces — ProstoCAD asks first and says what will go.
  • Hide, Show and Show All (View ▸ Visual Style ▸ Hide / Show, and in the right-click menus) hide or show the selected solid, assembly part, origin plane or axis, the Center Point or a sketch; a hidden one is picked by its browser row. Show All brings back every hidden solid of the part, every hidden part of the assembly, with nothing to pick.

3.5 The Parameters panel

Below the browser, PARAMETERS lists the part's values in three columns: Name, Value (what you typed — a number or a formula) and Result.

  • Model parameters (shown in the accent colour) are made automatically: every sketch dimension and every feature value gets the next free name d0, d1, d2 …; assembly constraint values are named after the constraint (Mate1, Angle1 …). Type a new name over a model parameter to rename it — formulas that use it follow.
  • Your own parameters: click +, type a name, press Tab and type the value (Width, 40 mm). Use the name in any value box or dialog field.
  • Change a value in the Value column and the model updates.
  • − removes the selected parameter. A value that is still used (by a feature or a formula) is not removed: the status line says what uses it. This is how you clean up values left behind by deleted features. A sketch dimension (d1, d2…) is deleted from its sketch the same way; one that a formula uses stays.
  • While a value box or a dialog field is open, click a parameter's name to insert it into the formula.

View ▸ Windows ▸ Parameters (or the marking menu) opens the Parameters window: every parameter in one big table you can resize — Name, Value, Result and Used by (the features, sketches and formulas that use it; «— not used» in grey). It stays open while you work and follows every change. Type a value or a formula in Value, type a new name over a dimension or a feature value to rename it, + Add and − Remove as in the panel, Find a name narrows the list, and Delete Unused removes every value nothing uses (values left behind by deleted features) in one undo step.

3.6 Values, units and formulas

Wherever ProstoCAD asks for a length or an angle you can type:

  • a number, in the file's units (12), or with units (12 mm, 0.5 in, 30°);
  • a parameter name (d3, Width);
  • a formula (d0/2, Width - 2*d3, d3*2).

A value that is a formula updates whenever the values it uses change.

3.7 The status line

At the bottom of the window: on the left, what to do next (for example "Pick a plane or a flat face for the new sketch") and messages — in orange or red when something did not work, so look here first when "nothing happens". On the right: the units of the file (mm · deg), while sketching the sketch's freedom (DOF: 3 or Fully constrained ✓ — click it to see the free geometry), and the size of the part (2 solids · 14 features).

3.9 Undo and Redo

⌘ Z undoes, ⇧ ⌘ Z redoes (also the title strip buttons and the NW / NE slots of the marking menu). Every operation is one undo step: a feature made in a dialog, a delete with its helpers, a hide, a drag of an assembly part. Inside a feature dialog, Undo steps back through the dialog's own changes. Undo also works in a sketch.

While a feature dialog is open, commands that would interfere with it (Save, Undo outside the dialog, editing a sketch) are refused with "Finish the … dialog first". Click OK or Cancel first.

3.10 Files

New (⌘ N) makes a part or an assembly (as chosen at the first start), File ▸ New Assembly always an assembly. Open (⌘ O), Save (⌘ S), Save As (⇧ ⌘ S) work on the file in front. Close (⌘ W) asks whether to save changes (Save, Don't Save, Cancel); Quit (⌘ Q) asks about every changed file. Each open file has its own tab above the view. The Open window (and Import, Place) shows a picture of the file under the pointer — the view a FreeCAD file was saved with, an STL, STEP or IGES drawn shaded (a STEP over 40 MB is not read) — with its date and size.

Open lists FreeCAD files, STEP and STL only. A JPG, PNG or BMP to sketch over: Image ▸ Insert Image (6.19). View ▸ Capture ▸ Screenshot (also File ▸ Screenshot) saves the 3D view as PNG, JPEG or BMP at the screen's full resolution (twice the window's size on a Retina screen); a PNG can have a transparent background, for a web page. Screenshot (Window) (the arrow beside it) saves the whole window — ribbon, browser, 3D view and status bar.

5Sketching

Sketches work as in Inventor: draw roughly, then dimension and constrain. Every dimension has a name you can use in formulas.

5.1 Starting a sketch

  1. Select a flat face of the part or a plane (in the view or the browser) — or select nothing.
  2. Press S, or click 3D Model ▸ Sketch ▸ Start 2D Sketch, or right-click ▸ Start 2D Sketch (N in the marking menu).
  3. With nothing selected, ProstoCAD shows the origin planes and a small panel New sketch on with XY · Top, XZ · Front and YZ · Right: click a button, or click a plane or a flat face in the view. Esc or Cancel gives up.

Double-clicking an origin plane in the browser also starts a sketch on it (on a work plane: right-click ▸ New Sketch). To edit an existing sketch, double-click it in the browser (or right-click ▸ Edit).

To leave the sketch: Sketch ▸ Exit ▸ Finish Sketch, N in the marking menu, or Esc (the first Esc stops a running tool).

5.7 Project Geometry and construction

6Part features

Every feature opens a dialog with a live preview. This chapter first explains how the dialogs work, then each feature with what to pick and what each option means.

6.1 How feature dialogs work

  • Select first or pick later. Select the faces, edges or sketch first and then click the command — or click the command and pick in the view or the browser while the dialog is open. The highlighted field takes the picks. Click another pick field (Select…) to make it take the next picks. While you pick, the shape as it was before the feature is shown, so you can reach every face.
  • The profile. Extrude and Revolve take the only finished sketch no feature uses yet automatically; if there are several, select one. If a sketch has crossing lines, ProstoCAD shows its areas: click the one to use.
  • Preview. Every change shows on the model at once. While you pick edges or faces, Fillet, Chamfer and Move Face draw the result's new edges over the part in orange. The full check of the result's geometry runs on OK; if it finds a problem, the dialog stays open and says what.
  • Values. Type numbers with or without units, names or formulas (3.6). The ▲ ▼ arrows next to a value — and the ↑ ↓ keys — change it by one unit (1 mm, 1°, 1/16 in); with ⇧ by ten. A formula cannot be stepped. The parameter's name is shown after the field's label, for example Distance (d19); click a parameter in the Parameters panel to insert its name.
  • Choices. Options are buttons; long lists wrap four to a row. A choice that cannot be used with the current picks is greyed out. Choosing an option that needs a pick starts that pick.
  • Buttons. OK makes the feature and closes the dialog. Apply + makes it and keeps the dialog open for one more of the same kind, with the same settings (only the picks start empty). Cancel or Esc leaves everything as it was.
  • Errors appear in red at the bottom of the dialog, in plain words ("Pick the cylindrical face to thread"). Sometimes the dialog offers a button with a way around the problem.
  • Editing. Double-click a feature in the browser (or right-click ▸ Edit) to open its dialog again with its values. As in Inventor, while the dialog of an earlier feature is open the part is shown as of that feature, and only that feature is recomputed as you change values; the features after it are recomputed once, on OK. If one of them fails then, the status line says which.

Esc stops long work. A long recompute stops between features when you press Esc (the rest is computed on the next recompute); so does the Emboss check. One kernel operation (a single Boolean, offset or fillet) still runs to its end.

A Solid almost symmetric about the plane gives a copy right on top of itself: pick another plane. 6.16 Emboss

3D Model ▸ Create ▸ Emboss (Inventor's Emboss / Engrave) raises a Text or a sketch from a face or cuts it in — any closed profile: letters, a star, a logo.   2. For a sphere: put the sketch on any plane, best one through the sphere's centre or in front of it; the profile lands on the half of the sphere that faces the sketch.
  3. Press Emboss: the Text (or the selected sketch) is taken as the profile and the Face field waits — click the round, spherical or flat face. A sketch left in another solid moves to the solid of the face you click, with the emboss.
FieldChoices and meaning

6.17 Spur Gears and Worm Gear

3D Model ▸ Create ▸ Spur Gears (split button with Worm Gear) makes a pair of gears in mesh in one dialog, as Inventor's Design Accelerator — no sketch. Each gear is a Solid of its own; Make Assembly (the Assembly tab) then puts each into a part file of its own and builds the assembly, so any gear can be opened and saved anywhere. Involute teeth (the standard tooth: addendum 1 module, dedendum 1.25 modules).

  1. Press Spur Gears and press OK: a pair 20 and 30 teeth, module 2 mm, ready. The line under the fields says what the numbers make: teeth, pitch diameters, ratio, centre distance.
  2. Both gears: Module, Pressure angle (20° standard), Helix angle (0° spur; 5–45° helical — gear 2 gets the other hand by itself), Hand of gear 1. Make: Pair or One gear.
  3. Gear 1: Teeth, Width, Bore Ø (8 mm; 0 = none). Gear 2: Size by Teeth, Ratio (1.5: half as many teeth again) or Center dist. (the nearest whole number of teeth), Width, Bore Ø.
  4. Place (optional): Axis (a work axis, a sketch line — a construction line too — or a straight edge), Center (a circle: a shaft's end, a hole, a sketch circle — its centre and plane; a corner or a work point) or Plane.   5. Mesh with (Both gears) puts gear 1 in mesh with a gear already there — a third gear for a pair: click that gear. Module, pressure and helix angle then come from it; Around it turns gear 1 round it (degrees from its X), Around gear 1 (Gear 2) does the same for gear 2. A worm can mesh with a gear already there the same way.

Moving it. Gear 1 carries the assembly's gizmo — while the dialog is open, and whenever you click a gear of the set in the part: drag an arrow to slide the pair along gear 1's X, Y or Z (whole mm; hold ⌘ for any value), an arc to turn it round its axis or tilt it round X or Y (5°). 3D Model ▸ Create ▸ Worm Gear: the worm and its wheel in one dialog. Worm: Module (axial), Pressure angle, Hand, Starts (1–6), Pitch Ø, Length, Bore Ø; Make: Worm and wheel or Worm only. 6.20 Boss, Lip / Groove, Snap Fit and holes for inserts

Tools for printed boxes and covers: Boss — posts for screws or threaded inserts; Lip / Groove — a raised band on the rim of a box and the groove for it in the lid, so the two halves line up and close tightly; Snap Fit — flexible hooks that click the lid on without screws; Hole ▸ Insert — a hole for a heat-set brass insert anywhere. They are in 3D Model ▸ Create ▸ Boss (the arrow beside it: Lip / Groove, Snap Fit). Each is a step of the part: it follows its sketch or face when they change, and a double click on it opens its dialog again.

First: the box

  1. Sketch a rectangle (with rounded corners if you like) and Extrude it to the box's outside height.
  2. Shell, click the top face, Thickness 2 mm (for printing: 1.6–2.4 mm). The box is open at the top; the top of its walls is the rim.
  3. The lid is made the same way in its own part: a shallow box, its rim facing the box's rim.

  2. Create ▸ Boss and click the sketch (or select it first). A boss stands on every point.
  3. Set the fields (below) and press OK.

7Several solids in one part

A part can hold several separate solids — for a tool and the part it cuts, or a part you will print in pieces.

How separate solids are made

  • Extrude with Operation ▸ New Solid.
  • An Extrude ▸ Join that does not touch the part (a box drawn away from it): it becomes its own solid automatically.
  • Split ▸ Keep all: every piece except the largest becomes a solid.
  • Boolean with Keep tool, or a "<Tool> fit" copy (Clearance on Tool).

The browser then shows Solid Bodies (n) with a row for each solid. The history stays one list: features of other solids name their solid.

Sketching on another solid

A new solid sketched on a face of another solid holds only its own piece; the solid below stays as it is. The sketch follows that face only when it projects edges of the other solid; otherwise the face only gave it its plane.

Hide, show, rename, delete

Right-click a solid's row: Hide / Show, Rename, Show in Window, Delete. A hidden solid is dimmed in the browser. Delete asks when the solid is used by a Boolean (both go together) or when it is the main solid (the next one becomes the main solid). Selecting a piece in the view and pressing ⌫ deletes that solid.

Edit on a solid's row works on that solid with the other solids see-through, so you see how a lid sits on its jar; Esc or Edit again ends it. Inspect ▸ Analyze ▸ Interference shows in red where the solids of the part go into each other, with the volume of each overlap.

Make Assembly

When the pieces are ready, 3D Model ▸ Assemble ▸ Make Assembly turns every separate piece into a part file of its own and links them in a new assembly where they were. See 9.12.

9Assemblies

An assembly links part files and holds them together with constraints and joints, as in Inventor. The parts stay separate .FCStd files.

9.1 Starting an assembly

  • File ▸ New Assembly, or Get Started ▸ New Assembly with no file open.
  • New (⌘ N) makes an assembly too if you chose Assembly with Remember my choice. Tools ▸ Options ▸ Ask on New brings the question back.

An assembly links to part files, so it must be saved before the first part is placed. ProstoCAD does this for you: when you place the first part, a new assembly is saved next to that part under its own name; if a file of that name is already there, ProstoCAD asks for a name and a folder. Create asks you to save the assembly first.

9.2 Placing and creating parts

  1. Assemble ▸ Component ▸ Place (P) — or N in the marking menu.
  2. Choose a saved part (or assembly) file.
  3. The first part placed is grounded (fixed in place); the next ones are put beside it.

Create asks for a New part file name and makes a new, empty part file next to the assembly, placed in it. Ground grounds or ungrounds the selected part.

9.3 The assembly browser

In an assembly the browser shows the assembly, one row per part, and Relationships (n) with the constraints and joints.

  • Each part row shows its freedom: grounded, DOF 0 … DOF 6, or DOF ? when it could not be counted (hover for the reason). A suppressed part shows nothing.
  • Under each part row is the part's own history (its sketches and features). A click on one of those rows selects the part; a double-click opens the part file.
  • A hidden part is dimmed, a suppressed one struck through.
  • Right-click a part (row or in the view) for Edit, Hide / Show, Suppress, Remove from Assembly, Ground and the constraints (4.2).

9.4 Adding a constraint or a joint

  1. Click the constraint on Assemble ▸ Constrain or Assemble ▸ Joint — C is Mate, J is Rigid — or use the marking menu on a face or edge of a part.
  2. Pick the First item on one part and the Second item on another, in the 3D view. The preview moves the part at once.
  3. Set the Offset or Angle if the constraint has one, and Flip if the part faces the wrong way.
  4. OK (or Apply + for the next one).

The part that moves is the free one; a grounded part never moves. A constraint that cannot be met together with the others is refused: "Mate conflicts with the other constraints (it can't be met)". Offsets and angles are parameters named after the constraint — Mate1, Flush1, Angle1 … — and appear in the Parameters panel.

Every constraint and joint has a row under Relationships. Double-click a row to edit it. Right-click it for Edit, Delete, Suppress / Unsuppress and Rename. A suppressed constraint is struck through; the solver ignores it and its parts stay where they are. Bringing back a constraint that can no longer be met is refused.

9.7 Degrees of freedom

A part's degrees of freedom are the ways it can still move: up to three slides and three turns. ProstoCAD counts them against what holds the part (the other free parts are held still while it counts):

  • the part row says grounded, DOF n or DOF ? (9.3);
  • View ▸ Visual Style ▸ Degrees of Freedom (View tab of the assembly) draws Inventor's DOF symbols on every free part — a double arrow for each direction it can slide, an arc for each axis it can turn about (figure 12);
  • with that button off, the part under the pointer shows its symbol as a tip.

A fully constrained part (DOF 0) and a grounded part show no symbol.

9.8 Moving parts

Drag a free part with the left button: it moves only the ways its constraints still let it — a Mated block slides and turns on its face, an inserted pin turns in its hole. The other parts stay where they are, even free ones. A fully constrained part does not move (the status line says "… is fully constrained"); a drag on a grounded part says it is grounded.

The gizmo. Click a free part: its DOF symbol becomes a gizmo with an arrow for each direction it can slide and an arc for each axis it can turn about.

  • Grab an arrow to slide the part, an arc to turn it. Handles are easy to catch: the one under the pointer lights up.
  • The first arrow is up and down — straight up, or up the slope of a tilted face — where the part can move that way.
  • A click on empty space hides the gizmo.

Every drag that moved the part is one undo step ("Move part"); ⌘ Z puts the part back. While a constraint dialog is open, dragging is off.

9.9 Editing a part in the assembly

Right-click a part ▸ Edit (or double-click its row): the part opens in its own tab, with the other parts of the assembly drawn around it — grey, semi-transparent, at their real places. They are for reference only: they cannot be picked and are not saved in the part. Change the part as usual and save it.

View ▸ Assembly Context (View menu, or the View tab of the part) turns the other parts off and on.

Right-click a part ▸ Open (also Assembly ▸ Component ▸ Edit | Open) opens its file in its own window as a part of its own — no assembly around it and no Return, as Inventor's Open.

Saving an assembly: the first Save (or Save As) asks for a name and a place and makes a folder of that name there: the assembly and every part file it uses (a sub-assembly's too) are saved into it, and the assembly links to those copies. The files the parts came from are left as they were. Later Saves keep it all in that folder.

  1. Save the part — the new files go into its folder.
  2. 3D Model ▸ Assemble ▸ Make Assembly, or right-click in empty space ▸ Make Assembly.
  3. The dialog lists the new files: the Assembly name and one name per piece (Piece 1 (grounded), Piece 2 …) with its volume. Hover over a row to see the piece marked in the view. Change the names if you like.
  4. Click OK. The new assembly opens.
  • Every separate piece becomes a part file with its history; the assembly links them where they were, the largest piece grounded.
  • Gears (6.17) are not grounded: each stands on its own axis — a Rotational joint to Gear Axes, a hidden grounded copy of their bore circles. Select a gear and drag the gizmo's arc: it turns, and the gears in mesh with it turn by their ratio (a worm and its wheel too).
  • The original part is not changed.
  • Running Make Assembly again on the same part offers Replace existing files (with the names of the files already there), so the files of the earlier run are overwritten instead of asking for new names. The part itself is never replaced. If one of those files is open with unsaved changes, ProstoCAD asks first.
  • A part of one piece makes an assembly of one component (a single gear, say). To get several components, split it first (Split ▸ Keep all) or make pieces as New Solid. Gears of a set (6.17) each go into a part file of their own, still in mesh.

9.13 Boolean between parts

Assemble ▸ Component ▸ Boolean cuts one part by others, for example a pocket for a bearing:

FieldMeaning
Cut thisThe part to cut.
WithThe part(s) that cut it.
ClearanceA gap for printed parts (0.2 mm).
Clearance onCavity, Tool or Split, as for the part Boolean (6.12).

The pocket is written into the cut part's own file and follows the tools when they move or change. Save that part file too. The cut gets a row under Relationships (Edit, Delete, Rename).

9.14 Threads Off / On in an assembly

Assemble ▸ Component ▸ Threads turns every thread of every part off (faster redraws) and back on. It changes the part files: save them with the assembly.

9.15 Saving

Save saves the file in the active tab. A part edited from the assembly, cut by a Boolean or changed by Threads Off / On is a file of its own: save it as well (switch to its tab, or let Quit ask about every changed file).

10Tips for 3D printing

ProstoCAD was made with printed parts in mind. A few habits save reprints.

  • Threads that fit. Thread and Hole ▸ Tapped have a Print clearance (on diameter), 0.2 mm by default (0.3 mm for a Print-friendly thread). Try it on a small test piece with your printer; raise it if a printed bolt is tight, lower it if it is loose. The Print-friendly thread standard has flat crests that print cleanly.
  • Lead-ins. Use Hole ▸ Chamfer (Start or Both ends) and Thread ▸ Chamfer so screws and nuts start easily.
  • Parts that fit into each other. Boolean ▸ Cut with Clearance (per side): on the Cavity to print the part with the hole, on the Tool to get a slightly smaller "fit" copy of the tool to print, Split for half on each.
  • Print the tool as well. Turn on Keep tool: the tool stays a visible solid of its own — the pin and the box with its hole.
  • Too big for the bed? Draw the cut lines in a sketch, Split ▸ Keep all, then Make Assembly: each piece becomes a part file you can export and print, and the assembly shows them together.
  • Weight and filament. Tools ▸ Material, then Inspect ▸ Mass Properties for the mass.
  • Fast work. Turn threads off (Threads) while modeling; turn them on before exporting.

11Troubleshooting and reporting a problem

When something does not work

  1. Read the status line and the red text in the dialog: ProstoCAD says why a command was refused and what to pick.
  2. A dialog is open? Commands like Save and Undo wait for OK or Cancel.
  3. A feature in red in the browser: hover over it for the reason, then edit it (double-click).
  4. The view or the browser looks out of step with the model: click Update on the title strip.
  5. Undo (⌘ Z) the last step.
  6. Still stuck: save under a new name, quit and restart FreeCAD.
  7. Return to FreeCAD always gives you FreeCAD's own interface on the same file.

Reporting a problem

Please send:

  • what you did, step by step, and what you expected instead;
  • the build name (the name of the zip file);
  • your macOS version and FreeCAD version (FreeCAD ▸ About FreeCAD);
  • the log file ~/Library/Logs/InCad.log — ⚙ ▸ Show Log File shows it in the Finder;
  • if you can, the .FCStd file you were working on;
  • a screenshot if something looks wrong.

If FreeCAD crashed, macOS shows a crash report: please copy its text as well.

Known limits of this build

  • macOS on Apple Silicon only; FreeCAD 1.1 (tested with 1.1.3).
  • A test build. Save often and work on copies.
  • The interface is in English.
  • FreeCAD cannot shell a part that already has a modeled thread (ProstoCAD offers to shell before the thread).
  • Some offsets fail on threads and other complex shapes (an Emboss). A Boolean's clearance then falls back to 0 mm (the field and the status line say so); a fit copy is not made.
  • Mirror Solid ▸ Join / Cut and Boolean need a result in one piece: a mirror image crossing the part in many places can leave separate pieces (the dialog says so — try another plane, One side / Other side, or New Solid). A part almost symmetric about the plane gives a copy right on top of itself.
  • A mirrored Solid used as a tool by a Boolean on its own original follows the original only up to the step before that Boolean. Make Assembly keeps mirrored Solids as they are (no link between part files).
  • Move Face moves flat faces along their own direction and straight round walls outward / inward. In Inventor mode it cannot follow a neighbour that is round across the move yet (use Step or Together); Together inward next to fillets or chamfers on a round wall is refused for now.
